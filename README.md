# Инициализатор Debian

Инициализационный скрипт нового хоста обновляет пакеты, задаёт параметры ядра, настраивает аудит и SSH и подготавливает интерактивную среду. [Исходный код](init/debian.sh)

## Термины и определения

| Термин | Значение |
| --- | --- |
| APT | Менеджер пакетов Debian. Индексы APT описывают доступные пакеты, а источники задают архивы и выпуски для их загрузки. |
| deb822 | Формат источников APT с группами именованных полей в файлах с расширением .sources. Однострочные источники обычно находятся в файлах .list. |
| Установщик | Bash-скрипт init/debian.sh. Принимает параметры запуска и ввод администратора, затем изменяет конфигурацию хоста. |
| Управляемый файл | Файл, который установщик записывает через write_config с заданным режимом доступа и владельцем root:root. |
| OpenSSH | Клиент и сервер SSH. SSH-агент предоставляет публичные ключи для добавления в список разрешённых ключей root, а sshd обслуживает входы. |
| systemd | Менеджер служб и таймеров. Установщик через него управляет SSH, аудитом, журналом и обновлениями. |
| PAM | Стек модулей, который sshd использует при открытии сеанса. pam_motd собирает вывод MOTD, а pam_exec передаёт поля предыдущего входа. |
| MOTD | Сообщение при входе. Генератор 10-sysinfo формирует сведения о системе. Файл /etc/motd может содержать текст администратора. |
| Журнал входов | База wtmpdb в /var/log/wtmp.db. Она хранит записи терминальных входов, из которых баннер берёт сведения о предыдущем SSH-сеансе. |

## Архитектура

~~~text
Запуск init/debian.sh
  ↓
Вход через терминал — main
  ↓
Предварительные проверки — initialize_host
  ↓
Обновление системы — initialize_host
  ↓
Имя хоста, ключи и часы — initialize_host
  ↓
Пакеты и рабочая среда — configure_base_software
  ↓
Параметры ядра — configure_network
  ↓
Аудит, журнал, баннер и SSH — configure_security
  ↓
Обновления безопасности — configure_security_updates
  ↓
Завершение запуска — main
  ↓
Настроенный хост и интерактивная оболочка
  ↓ новый интерактивный SSH-вход
SSH-баннер — PAM
  ↓
Сведения о системе, предыдущий вход и приглашение оболочки
~~~

### Вход через терминал

Из корня репозитория запустите установщик в терминале root. На удалённом хосте используйте SSH-подключение по IPv4. Команда без аргументов задаёт порт 22221. Параметр --ssh-port принимает порт от 1 до 65535. Параметр --help выводит справку.

~~~bash
bash init/debian.sh
~~~

Запуск на целевом хосте хосте.

~~~bash
curl -fsSL https://raw.githubusercontent.com/Qedr1/sre/main/init/debian.sh | bash
~~~

| Функция | Вход и результат |
| --- | --- |
| main | Получает аргументы запуска. Открывает управляющий терминал и передаёт его для ввода и вывода initialize_host. |
| parse_args | Разбирает параметры и проверяет номер порта. При запросе справки выводит её и завершает запуск. |

### Предварительные проверки

Проверки выполняются до обращения к APT. Второй запуск завершится на этом этапе, если блокировка уже занята.

| Функция | Вход и результат |
| --- | --- |
| initialize_host | Принимает выбранный порт и управляющий терминал. Задаёт системный PATH и локаль C, запускает проверки, ставит блокировку на /etc/sysctl.d и создаёт временный каталог. Управляет дальнейшим порядком настройки. |
| preflight | Проверяет запуск от root, Debian 13 amd64, кодовое имя выпуска, наличие /run/systemd/system, состояние ssh.socket и адрес текущего SSH-клиента. Продолжает при выключенном и неактивном ssh.socket и при IPv4-подключении либо локальном запуске. |
| write_config | Принимает файл, режим доступа и содержимое из стандартного ввода. Создаёт временный файл в каталоге назначения. При совпадении содержимого, владельца и режима действующего обычного файла удаляет временную копию. В остальных случаях заменяет файл с заданным режимом и владельцем root:root. |
| fail | Печатает сообщение с префиксом init-host в стандартный поток ошибок и завершает работу с кодом 1. |
| cleanup | При выходе удаляет подготовленный временный файл и рабочий временный каталог. При SIGINT и SIGTERM установщик выходит с кодом 130 и 143 соответственно. |

### Обновление системы

До запроса имени хоста установщик подготавливает источники APT и обновляет систему. Хосту нужен доступ к настроенным архивам. Для распознанных источников текущего Debian устанавливаются компоненты main, non-free, contrib и non-free-firmware.

| Функция | Вход и результат |
| --- | --- |
| configure_apt_sources | Получает кодовое имя Debian. Через apt-config определяет активные пути и обрабатывает однострочные источники и deb822. При отсутствии сетевых источников добавляет базовый архив, обновления и архив безопасности. Если сетевые источники есть, для продолжения нужен хотя бы один распознанный источник текущего Debian. |
| trim | Возвращает строку без пробельных символов по краям. |
| network_uri | Распознаёт сетевой адрес источника. Учитывает HTTP, HTTPS, FTP, FTPS и синтаксис mirror. |
| debian_uri | Распознаёт сетевой источник Debian по адресу официального архива или по стандартному файлу ключей Debian. |
| current_suite | Проверяет, равен ли выпуск кодовому имени системы или начинается ли он с этого имени и дефиса. |
| legacy | Разбирает одну строку deb или deb-src. Заменяет компоненты распознанного текущего источника, сохраняя адрес, выпуск, параметры и комментарий. |
| flush_stanza | Обрабатывает группу полей deb822. Для активного текущего источника Debian записывает Components. При сочетании распознанных и посторонних адресов или выпусков в такой группе требует разделить её. Сохраняет содержимое отключённых групп. |
| upgrade_system | Обновляет индексы APT с пределом 120 секунд. Загружает пакеты обновлений с пределом 600 секунд, затем применяет загруженные пакеты без сетевой загрузки. Разрешает добавлять зависимости обновляемых пакетов и передаёт dpkg параметры --force-confdef и --force-confold. |

### Имя хоста, ключи и часы

После обновления установщик запрашивает имя хоста и добавляет ключи root. Затем применяет введённое имя через hostnamectl и проверяет синхронизацию часов.

| Функция | Вход и результат |
| --- | --- |
| read_host_settings | Показывает текущее имя. Пустой Enter сохраняет его. Для нового имени проверяет длину каждой DNS-метки от 1 до 63 символов и общую длину до 64 символов. Принимает ASCII-буквы обоих регистров и сохраняет их регистр. |
| configure_root_keys | Берёт строки публичных ключей из ssh-add -L. При пустом результате или ошибке запрашивает один ключ вручную. После записи предлагает ещё один ключ. Пустой Enter пропускает дополнительный ввод. |
| install_root_key | Принимает строку обычного публичного ключа OpenSSH. Проверяет формат и вычисляет отпечаток SHA-256, сохраняет существующие записи и добавляет ключ при отсутствии совпадения. Режим каталога /root/.ssh равен 0700, файла /root/.ssh/authorized_keys — 0600. |
| configure_time_sync | Устанавливает systemd-timesyncd при отсутствии службы синхронизации, доступной через timedatectl. При необходимости включает синхронизацию и ждёт подтверждения до 60 секунд. Затем сообщает результат, и установка продолжается. |

### Пакеты и рабочая среда

Этот этап дополняет обновлённую систему обязательными пакетами и настраивает tmux и интерактивный Bash. Этот же механизм устанавливает openssh-client при настройке ключей, systemd-timesyncd при настройке часов и unattended-upgrades при включении обновлений безопасности.

~~~text
auditd openssh-server openssh-client libpam-modules
tmux bind9-dnsutils net-tools iperf3 ethtool bash-completion sqlite3
curl mtr-tiny mc htop bwm-ng iptraf-ng zstd
~~~

| Функция | Вход и результат |
| --- | --- |
| install_packages | Принимает список имён пакетов. По базе dpkg определяет отсутствующие пакеты, загружает их с пределом 180 секунд и устанавливает без рекомендуемых зависимостей. |
| configure_base_software | Передаёт обязательный список в install_packages, затем запускает настройку tmux и Bash. |
| configure_tmux | Записывает /etc/tmux.conf. Включает мышь, горизонтальное и вертикальное разделение панелей клавишами / и -, верхние заголовки панелей и автоматические имена окон по текущей команде. Показывает имя хоста в строке состояния. |
| configure_bash | Заменяет управляемый блок в /etc/bash.bashrc. Для интерактивного Bash задаёт автодополнение, добавление истории, поиск по истории стрелками и обновление размеров терминала. |
| __devhost_first_prompt | Однократно устанавливает приглашение с временем, пользователем, именем хоста и рабочим каталогом. При 256 цветах использует цветной вариант. После настройки удаляет себя из PROMPT_COMMAND и возвращает исходный код завершения. |

### Параметры ядра

Установщик сохраняет действующие значения и применяет следующие параметры. Этот этап включает пересылку IPv4 и отключает IPv6.

~~~text
net.ipv4.ip_forward = 1
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv4.conf.all.rp_filter = 2
net.core.wmem_max = 33554432
net.ipv4.tcp_rmem = 4096 131072 33554432
net.ipv4.tcp_wmem = 4096 16384 33554432
net.ipv4.tcp_congestion_control = bbr
net.core.default_qdisc = fq
~~~

| Функция | Вход и результат |
| --- | --- |
| configure_network | Считывает исходные параметры, загружает новые и запускает проверку. При успехе сохраняет /etc/sysctl.d/10-network.conf и настраивает его загрузку через ссылку 99-devhost-network.conf после стандартных настроек Debian. При сбое применения пытается восстановить исходные значения. |
| verify_network_settings | Сверяет действующие параметры с подготовленными значениями и проверяет, что флаг disable_ipv6 равен 1 у каждого доступного интерфейса. |

### Аудит, журнал, баннер и SSH

Этап получает установленные пакеты, выбранный SSH-порт и настроенное ядро. Он включает аудит исполнения и терминалов, записывает конфигурацию журналов и применяет параметры входа.

| Функция | Вход и результат |
| --- | --- |
| configure_security | Последовательно вызывает настройку auditd, ротации, аудита терминалов, journald, баннера, SSH-клиента, sshd и аутентификации. |
| configure_auditd | Записывает правила process_exec для execve и execveat с архитектурами b64 и b32, запускает auditd.service, включает её автозапуск и audit-rules.service. Загружает правила при необходимости и включает аудит ядра, если он отключён. |
| execution_rules_active | Проверяет по auditctl -l наличие обоих правил process_exec. |
| configure_audit_retention | Обновляет заданные параметры /etc/audit/auditd.conf и перечитывает конфигурацию при изменении файла. Для ротации задаёт max_log_file=32 и num_logs=8. Устанавливает пороги свободного места 15% и 10% с действиями SYSLOG и ROTATE. При заполнении диска задаёт ROTATE. |
| configure_tty_audit | Добавляет правило pam_tty_audit после pam_loginuid в PAM-стеках sshd и локального login. Включает аудит терминала для всех пользователей этих сеансов. |
| configure_journald | В /etc/systemd/journald.conf.d/60-devhost.conf задаёт постоянное хранение, MaxRetentionSec=3month, SystemMaxUse=4G и SystemKeepFree=1G. Перезапускает journald и сбрасывает журнал на диск. |
| configure_login_banner | Очищает /etc/update-motd.d в пределах его файловой системы, включая скрытые и вложенные элементы, и записывает исполняемый 10-sysinfo. Удаляет из /etc/motd совпадающий стандартный текст Debian, сохраняя текст администратора. Добавляет один вызов режима --last-login в стек sshd. |
| configure_ssh_client | В /etc/ssh/ssh_config.d/10-devhost.conf включает Compression, задаёт ServerAliveInterval=30 и ServerAliveCountMax=3 для всех хостов и сверяет эффективные параметры. |
| configure_ssh_server | В /etc/ssh/sshd_config.d/10-devhost.conf задаёт выбранный порт, PAM, проброс агента, сжатие, ClientAliveInterval=30 и ClientAliveCountMax=3. Передаёт показ баннера и предыдущего входа PAM, проверяет конфигурацию и наличие слушателя. При сбое пытается восстановить прежний файл и перечитать конфигурацию службы. |
| verify_ssh_server_config | Читает эффективную конфигурацию sshd и сверяет порт, PAM, вывод при входе, проброс, сжатие и параметры проверки соединения. |
| wait_for_ssh_listener | До 10 секунд проверяет наличие слушателя sshd на выбранном порту. |
| configure_ssh_authentication | При подтверждённом входе root по ключу записывает /etc/ssh/sshd_config.d/05-devhost-auth.conf с AuthenticationMethods=publickey, PubkeyAuthentication=yes, PasswordAuthentication=no, KbdInteractiveAuthentication=no и PermitRootLogin=prohibit-password. Проверяет настройки в контексте подключения и после перечитывания конфигурации ждёт слушателя. При недоступном подтверждении сообщает, действует ли политика или её включение отложено. При сбое применения пытается восстановить прежний файл. |
| verified_root_key_session | Получает адрес и порт клиента из SSH_CONNECTION, проходит по родительским процессам и ищет в журнале службы SSH подтверждение входа root по ключу для этого подключения. |
| key_only_policy_active | Сверяет эффективную конфигурацию sshd и проверяет требование публичного ключа, доступ root по ключу и отключение парольной и клавиатурно-интерактивной аутентификации. |

### Обновления безопасности

После настройки SSH установщик задаёт автоматическую установку обновлений Debian Security.

| Функция | Вход и результат |
| --- | --- |
| configure_security_updates | В /etc/apt/apt.conf.d/99-devhost-security-upgrades задаёт ежедневное обновление индексов и установку обновлений Debian Security с отключённой автоматической перезагрузкой. Устанавливает unattended-upgrades и включает таймеры apt-daily и apt-daily-upgrade. |

### Завершение запуска

При успешной настройке initialize_host печатает итоговый SSH-порт и вызывает 10-sysinfo для вывода параметров системы. Затем main заменяет процесс интерактивным Bash в том же терминале.

### SSH-баннер

При новом интерактивном входе по SSH модуль pam_motd выводит поля 10-sysinfo, начиная с Distro, и пользовательский текст /etc/motd, если он задан. Затем pam_exec показывает сведения о предыдущей терминальной SSH-сессии. После последнего поля баннер оставляет пустую строку.

| Блок | Поле | Значение и источник |
| --- | --- | --- |
| Система | Distro | Отображаемое имя выпуска из PRETTY_NAME в файлах /etc/*release. |
| Система | Kernel | Имя и версия запущенного ядра из uname -sr. |
| Работа системы | Uptime | Время с запуска в читаемом виде из uptime -p. |
| Работа системы | Load | Средняя нагрузка за 1, 5 и 15 минут из первых трёх полей /proc/loadavg. |
| Работа системы | Processes | Группы процессов по имени пользователя из ps. Счётчик root берётся из групп с root в имени, user суммирует остальные группы, total суммирует все группы. |
| Ресурсы | CPU | Первая модель процессора из /proc/cpuinfo и количество записей processor, показанное как vCPU. |
| Ресурсы | Memory | Используемая, доступная и общая оперативная память из строки Mem команды free -htm. |
| Сеть | Hostname | Текущее имя хоста из команды hostname. |
| Сеть | IPv4 | Имя интерфейса и IPv4-адрес с префиксом из ip. Поле выводится для каждого адреса интерфейса с записью device в sysfs. |
| Сеть | DNS | Уникальные IPv4-адреса из строк nameserver в /etc/resolv.conf. Для ссылки на stub systemd-resolved используется читаемый /run/systemd/resolve/resolv.conf. |
| Предыдущий вход | Last | Имя пользователя из последней записанной терминальной SSH-сессии хоста. |
| Предыдущий вход | Last IP | Числовой IPv4- или IPv6-адрес из той же записи. |
| Предыдущий вход | Last Time | Время входа из той же записи, показанное в UTC. |

Запись предыдущего входа установщик читает из wtmpdb до записи текущего терминального входа OpenSSH. Для отсутствующего или недоступного значения выводится прочерк. Настроенное приглашение Bash показывает время оболочки, имя пользователя и хоста и текущий каталог.
